Importar relatório patrimonial

Aceita arquivo .csv, .xlsx ou .xls — pode ser a planilha oficial com os nomes de coluna originais ("Nº Patrimônio", "Nº PATRIMÔNIO FAPES...", "LOCALIZAÇÃO / REFERÊNCIA PARA BUSCA") ou o formato simplificado (numero_32, numero_66, descricao, setor_local). Se um item não tiver um dos dois códigos, isso é sinalizado automaticamente. Itens já existentes não são duplicados.

Registrar item não catalogado

Use isto quando encontrar fisicamente um bem que não está na lista importada. Preencha os códigos que conseguir ler na peça — se faltar algum, deixe em branco, isso é registrado automaticamente na observação.

Começar novo relatório

Use isto se algo deu errado na conferência atual (arquivo errado importado, dados bagunçados) e você precisa recomeçar. Antes de apagar, um backup automático dos dados atuais é baixado em Excel (.xlsx) — nada se perde.

O que vai acontecer: 1) o resultado atual é exportado automaticamente (a menos que você desmarque abaixo); 2) todos os itens são apagados desta tela; 3) você importa a lista novamente para começar do zero.
